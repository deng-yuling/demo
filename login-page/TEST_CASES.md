# 登录界面测试用例

## 测试范围

| 模块 | 说明 |
|------|------|
| `login-core.js` | 用户名/密码校验逻辑 |
| `index.html` + `login.js` | 页面展示与提交交互 |

演示账号：`admin` / `123456`

---

## 一、功能测试用例（手工）

| 编号 | 场景 | 输入用户名 | 输入密码 | 预期结果 |
|------|------|------------|----------|----------|
| TC-01 | 正常登录 | admin | 123456 | 提示「登录成功」，绿色文案 |
| TC-02 | 用户名为空 | （空） | 123456 | 提示「请输入用户名」，红色 |
| TC-03 | 密码为空 | admin | （空） | 提示「请输入密码」，红色 |
| TC-04 | 全空提交 | （空） | （空） | 提示「请输入用户名」，红色 |
| TC-05 | 用户名错误 | root | 123456 | 提示「用户名或密码错误」 |
| TC-06 | 密码错误 | admin | 000000 | 提示「用户名或密码错误」 |
| TC-07 | 用户名过短 | ab | 123456 | 提示「用户名至少 3 个字符」 |
| TC-08 | 密码过短 | admin | 12345 | 提示「密码至少 6 个字符」 |
| TC-09 | 用户名含首尾空格 | ␣admin␣ | 123456 | 登录成功（自动去空格） |
| TC-10 | 大小写错误 | Admin | 123456 | 登录失败 |

---

## 二、界面测试用例

| 编号 | 场景 | 操作 | 预期 |
|------|------|------|------|
| UI-01 | 页面加载 | 打开 index.html | 显示标题、输入框、登录按钮 |
| UI-02 | 焦点样式 | 点击输入框 | 边框高亮 |
| UI-03 | 回车提交 | 填好后按 Enter | 触发校验，显示提示 |
| UI-04 | 错误提示区 | 校验失败 | `#message` 显示红色错误 |
| UI-05 | 成功提示 | 校验成功 | `#message` 显示绿色成功 |

---

## 三、自动化测试（可执行）

```bash
cd login-page
node --test test_login.mjs
```

覆盖：空值、长度、错误凭证、正确登录、trim、大小写、场景矩阵。

## 四、安全相关（说明性，当前演示版）

| 编号 | 场景 | 说明 |
|------|------|------|
| SEC-01 | 明文密码 | 演示版未加密，生产需 HTTPS + 后端校验 |
| SEC-02 | 暴力破解 | 生产应加验证码/限流 |
| SEC-03 | XSS | 提示文案使用 textContent，不插入 HTML |
